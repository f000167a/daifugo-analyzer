# 大富豪 勝率シミュレータ (Daifugo Win-Rate Analyzer)

モンテカルロ法を用いた、大富豪の初期手札から各順位への着地確率を算出するWebアプリケーションです。
指定されたルールやプレイヤー人数に基づき、AIが内部で仮想ゲームを数百回自動プレイし、統計的な勝率を導き出します。

## 機能特徴
- **StreamlitによるモダンなUI**: 数値を直感的に上下させるだけで手札を入力可能
- **ガチ勢の思考を再現したAIエンジン**: 敵の残枚数や危険度に応じた「強札の温存/即切り」「ペア崩し抑制」などを実装
- **役職別サバイバルアドバイス**: 現在の役職（富豪・平民・貧民）に応じて、都落ちリスクや現状維持戦略を自動言語化

## 採用ルール
- 人数：3〜5人（デフォルト3人）
- 8切り：ON/OFF切り替え可能
- ジョーカー：最大2枚（通常・革命時ともに最強札）
- 革命：4枚出しで成立（マーク不問、階段なし）
- スペード3返し / 階段 / 縛り：なし
